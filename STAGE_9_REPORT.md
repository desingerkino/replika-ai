# Отчёт: Этап 9 — КИНОРЕЖИМ

Дата: 25.09.2026. Версия 0.8.0 (схема базы v1 не менялась).

## Главное и порядок этапов

Этап 9 сделан раньше 7б и 8, и это сознательно.
- **7б** (запись с микрофона и камеры) и **8** (уведомления) добавляют
  нативные плагины Android. Их надёжнее подключать после первой зелёной
  сборки с камерой из 7а.
- **Кинорежим** написан на чистом Dart, без новых плагинов и разрешений.

Этап 9 **написан, но не собран**. Результатов сборок после 4.2 я не видел.

## РЕАЛИЗОВАНО (в коде; подтвердит только сборка и запуск)

- **Включение.** Операторская → «Кинорежим» (или Настройки → Дополнения →
  «Кинорежим», пока режим выключен). Состояние сохраняется
  и восстанавливается после перезапуска.
- **Своя строка состояния.** Системные панели скрываются: режим
  immersive sticky, свайп от края временно их показывает. Вместо них
  приложение рисует свою строку:
  - время — время сцены (если задано «время в кадре»), своё время,
    идущее от заданного (например, 02:15), или реальное;
  - заряд 0–100% и «заряжается»;
  - сигнал 0–3;
  - 4G / LTE / 5G / без значка;
  - Wi-Fi.

  Этим решено ограничение Этапа 5: часы в кадре теперь показывают нужное
  время. Над тёмными экранами (звонок, просмотр фото и видео) значки
  становятся светлыми. Экраны получают отступ, как под настоящей строкой.
- **В настройках скрыты служебные пункты:** «Медиатека», «Дополнения»,
  «О приложении» с версией.
- **«Назад» на главном экране** не закрывает приложение.
- **Вход в операторскую** в кинорежиме только скрытый: удержание «Чаты»
  2 секунды или три пальца 1 секунду.
- **Пульт громкостью, сцены, импровизация и звонки** работают
  без изменений.
- **Экран настройки** показывает, как будет выглядеть строка,
  и перечисляет настройки Android, которые приложение включить не может
  (см. ниже).

## СОБРАНО / ЗАПУЩЕНО / ПРОТЕСТИРОВАНО

Нет. Добавлено 4 автотеста, всего их 84: сохранение и чтение настроек,
повреждённые данные, три режима времени, значки заряда и сигнала.

## ОГРАНИЧЕНО ОС (сделать в настройках телефона перед съёмкой)

- **Кнопку «Домой» приложение заблокировать не может.** Используйте
  «Закрепление приложений» в настройках безопасности Android.
- **Уведомления других приложений.** Включите «Не беспокоить».
- **Экран может погаснуть в дубле.** Не давать экрану гаснуть без
  отдельного плагина нельзя — поставьте максимальный тайм-аут экрана.
  Плагин можно добавить вместе с Этапом 8.
- **Телефоны с вырезом под камеру.** При скрытых панелях Android может
  оставить над приложением чёрную полосу выреза. Своя строка тогда
  рисуется под ней. Зависит от модели — физически не проверено.

## НЕ ГОТОВО

- **10–11** — полировка и полная проверка.

## Как обновить на GitHub

В папке `lib` стало 102 файла, а в одну загрузку помещается 100.
Поэтому грузите в три приёма:
1. На GitHub откройте папку **lib** → **Add file → Upload files** →
   перетащите папки `features` и `app` → **Commit changes**.
2. Снова в папке **lib** → **Add file → Upload files** → папки `core`,
   `data` и файл `main.dart` → **Commit changes**.
3. В корне репозитория → **Add file → Upload files** → папки `test`,
   `assets`, `tool` и файлы `pubspec.yaml`, `README.md`,
   `STAGE_9_REPORT.md` → **Commit changes**.

Смотрите результат **последней** сборки.
