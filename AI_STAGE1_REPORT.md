# Реплика AI — этап 1: локальная модель на iPhone

**Статус: код написан, но НЕ собран и НЕ запущен.** В среде, где это писалось, нет Flutter, macOS и доступа к интернету из терминала. Сборку и замеры делает GitHub Actions и реальный iPhone.

## Решение по объёму
Версия с ИИ — только для iPhone 14 и новее. Android на этом этапе не трогаем.

## 1. Рантайм
`llamadart` 0.10.0 (pub.dev, llama.cpp, Metal на iPhone) + iOS-компаньон `llamadart_llama_cpp_flutter` 0.0.20. Один рантайм, другие не подключаются.

Требования пакета и как они сходятся с проектом:
| Требование llamadart | Проект сейчас | Итог |
|---|---|---|
| iOS 16.4+ | iOS 14.0 | В сборке AI поднимаем до 16.4. iPhone 14 выпущен с iOS 16, обновляется дальше |
| Dart ≥ 3.10.7, Flutter ≥ 3.38 | CI на `stable` | Совместимо, если stable не старше 3.38 (проверит шаг «Версии» в CI) |
| Сборка без своего C++ | — | Нативные библиотеки подтягиваются при сборке (нужен интернет в CI, не на телефоне) |

## 2. Модель
`ggml-org/Qwen3-1.7B-GGUF`, квантование **Q4_K_M**, ≈ **1,28 ГБ**, лицензия Apache-2.0. Репозиторий ggml-org ведут авторы llama.cpp.
Ссылка: https://huggingface.co/ggml-org/Qwen3-1.7B-GGUF

Важно: отдельной «Qwen3 1.7B Instruct» не существует. Qwen3-1.7B — уже дообученная (не Base) модель с режимом размышлений. В коде режим выключен (`enableThinking: false`), иначе ответы будут долгими.

**Модель мной не скачана** (нет сети), точное имя файла внутри репозитория не проверено. В Git не добавляется: `/models/` и `*.gguf` в `.gitignore`.

## 3. Что изменено в существующих файлах
- `tool/app_config.sh` — `IOS_MIN_VERSION` теперь можно переопределить (по умолчанию по-прежнему 14.0).
- `analysis_options.yaml` — анализатор пропускает папку `ai_edition/`.
- `.gitignore` — `/models/`, `*.gguf`.
Файлы `pubspec.yaml`, `lib/**`, тесты, Android-сборка и обычная iOS-сборка **не менялись**.

## 4. Новые файлы
- `ai_edition/lib/ai/local_llm_provider.dart` — интерфейс `LocalLlmProvider` (загрузка, выгрузка, генерация, состояние, ошибки, замеры). Ничего не знает о чатах.
- `ai_edition/lib/ai/llamadart_provider.dart` — единственное место, где упомянут llamadart.
- `ai_edition/lib/ai/local_ai_test_screen.dart` — экран Local AI Test (выбор .gguf, загрузка, «Ты дома?» → «Сгенерировать», замеры).
- `ai_edition/lib/main_ai.dart` — отдельная точка входа; обычный `lib/main.dart` не затронут.
- `tool/prepare_ai_ios.sh` — копирует слой в `lib/ai/`, добавляет зависимости (только в рабочей копии CI), ставит iOS 16.4.
- `.github/workflows/build-ios-ai.yml` — сборка «Сборка iOS AI (без подписи)», артефакт `replika-ai-ios-unsigned`.

## 5. Как проверить
1. GitHub → Actions → «Сборка iOS AI (без подписи)» → Run workflow.
2. Скачать `replika-ai-unsigned.ipa`, поставить через Sideloadly.
3. Скачать `Qwen3-1.7B-Q4_K_M.gguf` по ссылке выше на Mac, отправить на iPhone (AirDrop → «Файлы»).
4. В приложении: «Выбрать .gguf» → «Загрузить» → «Сгенерировать». Экран покажет размер файла, время загрузки, бэкенд (Metal/CPU), ОЗУ, время до первого токена, скорость и время ответа. Эти цифры нужны для отчёта.

## 6. Риски (не проверено)
- Сборка через Swift Package Manager не пробовалась: возможны ошибки на первом запуске CI.
- Имена методов llamadart взяты из документации 0.10.0; без компиляции возможны мелкие расхождения (например `getBackendName`, поля `usage`).
- Sideloadly с бесплатным Apple ID не даёт расширенный лимит памяти. Для 1,3 ГБ модели на iPhone 14 (6 ГБ ОЗУ) это должно хватать, но замер покажет.
- Подключение к чатам, персонажи, память — следующие этапы, здесь не делались.
