# iOS: подготовка и сборка

Папки `ios/` в репозитории нет, как и `android/`: её создаёт скрипт под
установленную версию Flutter, чтобы настройки Xcode всегда были совместимы.

## Что нужно

* Mac с актуальным Xcode (его версия должна подходить для вашего Flutter:
  `flutter doctor`). Mac на Intel с macOS Catalina для этого не годится: на
  нём нельзя поставить современный Xcode. Собирать можно на Mac с чипом M1
  и новее либо в GitHub Actions (`Сборка iOS (без подписи)`).
* Flutter (stable), CocoaPods (`sudo gem install cocoapods` или `brew install cocoapods`).
* Apple ID для подписи. С бесплатным Apple ID сборка на телефоне работает
  7 дней, затем её надо поставить заново; платный Apple Developer Program
  снимает это ограничение.

## Сборка и запуск на iPhone / iPad

```bash
bash tool/prepare_ios.sh          # создаёт ios/ и настраивает его
flutter pub get
cd ios
pod install
open Runner.xcworkspace
```

В Xcode: Runner → Signing & Capabilities → выбрать Team. Подключить
устройство, нажать Run. Из командной строки: `flutter run -d <id устройства>`.

Проверка без подписи (как в CI): `flutter build ios --release --no-codesign`.

Скрипт можно запускать повторно.

## Что настраивает `tool/prepare_ios.sh`

* Название «Реплика» и Bundle ID: `ru.kinoprop.replika`. Меняются только в
  `tool/app_config.sh` (там же `ORG` и минимальная версия iOS 14.0).
  Версия приложения берётся из `pubspec.yaml`.
* Иконка (`tool/ios_res/AppIcon.appiconset`, 1024 px без прозрачности; её
  генерирует `tool/generate_icons.py` из того же логотипа, что и на Android).
* Делегат локальных уведомлений в `AppDelegate.swift` (без него iOS не
  показывает уведомление, пока приложение открыто, и не передаёт нажатие).
* Ориентации и iPad берутся из шаблона Flutter (iPhone: портрет и
  ландшафт, iPad: все четыре, мультизадачность не отключена).

## Разрешения в Info.plist

Только то, что приложение действительно использует.

| Ключ | Зачем |
|---|---|
| `NSCameraUsageDescription` | своё изображение в видеозвонке, запись видеосообщений |
| `NSMicrophoneUsageDescription` | голосовые и видеосообщения |
| `NSLocalNetworkUsageDescription` | Connect: Prop Controller по Wi-Fi |
| `NSPhotoLibraryUsageDescription`, `NSAppleMusicUsageDescription` | выбор фото, видео и аудио для медиатеки (`file_picker`) |

Последние два ключа указаны по документации `file_picker`; если на реальном
устройстве окно доступа к фото или музыке не появляется и выбор работает,
ключ можно убрать.

Уведомления разрешаются во время работы: системный запрос появляется при
первом показе (или при включении переключателя в Настройки → Дополнения).

## Ограничения iOS

* **Кнопки громкости** приложению недоступны (без private API и обходов
  это невозможно). Ход сцены ведут кнопки операторской, скрытый жест
  двумя пальцами, внешняя клавиатура (стрелки, пробел, удержание Esc) и
  Prop Controller по Connect (`SCENE_NEXT`, `SCENE_PREVIOUS`, `SCENE_STOP`).
* **Фон.** При блокировке экрана iOS приостанавливает приложение, фонового
  аналога Android-службы нет. Пока Connect включён, экран не гаснет
  (wakelock), и Connect работает, пока «Реплика» открыта на экране. На
  съёмке: «Гид-доступ» и Автоблокировка «Никогда».
* **Поиск телефона по Wi-Fi** использует UDP-широковещание. На iOS 14+
  широковещательные и multicast-пакеты, по документации Apple, требуют
  entitlement `com.apple.developer.networking.multicast`, который выдаёт
  Apple по заявке и только для платного аккаунта. Без него автопоиск может
  не работать; подключение Prop Controller по IP-адресу телефона (порт
  Connect) от этого не зависит. Entitlement в проект не добавлен.
* **Своя строка состояния** кинорежима на iPhone с вырезом или Dynamic
  Island рисуется под системными элементами; сам вырез скрыть нельзя.
* Фокус «Не беспокоить» скрывает и уведомления «Реплики», если не
  разрешить приложение в Фокусе.

## Проверить на реальном устройстве

* Уведомления: запрос разрешения, баннер при открытом приложении, экран
  блокировки, нажатие открывает нужный чат.
* Камера и микрофон: видеозвонок, видеосообщение, повторное воспроизведение
  в чате, голосовое (запись → воспроизведение громкостью динамика).
* Выбор фото, видео и аудио в медиатеке.
* Connect с Prop Controller по IP; запрос «Локальная сеть» при первом запуске.
* Перезапуск: профиль, выбранная сцена, база, сброс сцены.
* Сохранение медиа после переустановки или обновления (пути к файлам
  привязываются к текущей папке приложения).
