# Отчёт: Этап 3 — медиа

Дата: 25.09.2026. Версия приложения 0.3.0 (схема базы v1 — не менялась).

## Главное

Этапы 1–2 собраны через GitHub Actions с первого раза, 32 автотеста пройдены.
Результатов проверки на телефоне пока нет.

Этап 3 **написан, но не собран**. В проект впервые добавлены нативные плагины
Android: выбор файлов, видео, аудио и доступ к папке приложения. Это самый
рискованный для сборки шаг, поэтому ошибки на первой сборке вероятнее,
чем раньше.

## СОЗДАНО

- Плагины:
  - `file_picker` 12 — системный выбор файлов;
  - `video_player` 2 — видео;
  - `just_audio` 0.10 — аудио;

- 6 новых файлов Dart:

  - общий аудиоплеер;
  - медиа-пузыри;
  - просмотр фото и видео;
  - экран медиатеки;
  - справочник видов файлов.
- Файл автотестов Этапа 3.

## РЕАЛИЗОВАНО (в коде; работу подтвердит только сборка и запуск)

- **Скрепка в чате:**
  - фото или видео (можно несколько);
  - голосовое сообщение из аудиофайла;
  - видеосообщение из видеофайла;
  - аудиофайл;
  - выбор из медиатеки.

  Текст из поля ввода становится подписью к первому файлу, ответ на
  сообщение сохраняется.
- **Фото** — превью с сохранением пропорций, время поверх снимка,
  полноэкранный просмотр с увеличением двумя пальцами.
- **Видео** — первый кадр в ленте, длительность, полноэкранный плеер
  с перемоткой.
- **Видеосообщение** — круг. Касание запускает со звуком, по краю
  идёт кольцо прогресса.
- **Голосовое** — кнопка, «волна» (проигранная часть подсвечивается),
  время. **Аудио** — название файла и полоса прогресса. Одновременно
  звучит только одно сообщение.
- **Медиатека** (Настройки → Медиатека):
  - фильтры по видам, добавление, прослушивание и просмотр;
  - удаление с предупреждением, если файл где-то используется;
  - на месте удалённого файла в переписке появляется «Файл удалён».
- **Файлы копируются внутрь приложения.** Если удалить оригинал из галереи,
  переписки и сцены не сломаются.
- **Фото профиля** в редакторе контакта и «Моём профиле»: выбрать,
  заменить, убрать.
- **Поиск и «Избранное»** показывают медиа-сообщения по виду: «Фото»,
  «Голосовое сообщение».

## СОБРАНО / ЗАПУЩЕНО / ПРОТЕСТИРОВАНО

Нет. Добавлено 7 автотестов, всего их 39. Проверяются:
- определение вида файла;
- подписи длительности и размера;
- стабильность «волны»;
- чтение медиа вместе с сообщением.

Воспроизведение и выбор файлов автотестами не проверяются: это работа
с телефоном.

## НЕ ПРОТЕСТИРОВАНО

- Системное окно выбора файлов на конкретном телефоне. На Huawei без сервисов
  Google оно выглядит иначе, но должно работать: используется стандартный
  выбор Android.
- Длинные видео (копирование может занять несколько секунд — над полем
  ввода видна полоса) и форматы, которые телефон не умеет проигрывать.
- Вертикальные видео и фото с поворотом: пропорции превью могут
  отличаться, тогда кадр обрезается по центру.

## ОГРАНИЧЕНО ОС

- Что видно в окне выбора файлов (галерея, «Файлы», облака), решает
  Android и производитель телефона.

## НЕ ГОТОВО

- **Запись голосового микрофоном и видеосообщения камерой прямо в чате.**
  Сейчас голосовые и видеосообщения добавляются из готовых файлов. Запись
  требует разрешений на микрофон и камеру; её лучше делать вместе
  со звонками (Этап 7), где камера нужна всё равно.
- **«Волна» у загруженных голосовых — декоративная.** Она стабильна для
  файла и похожа на речь, но не построена по реальной громкости. Настоящая
  волна появится у записанных в приложении голосовых.
- **Превью видео в списке медиатеки** — значок вместо кадра: десятки
  одновременно открытых видео перегружают телефон. В ленте чата кадр есть.

## Как обновить проект на GitHub

Загрузите через **Add file → Upload files** только изменившееся:
папки `lib` и `test`, файлы `pubspec.yaml`, `README.md` и `STAGE_3_REPORT.md`.
Всего 83 файла, в одну загрузку помещается до 100. Скрытую папку `.github`
загружать не нужно: файл сборки на GitHub уже есть.
