# Этап 1: цвета участников групп, миграция БД v3

Статус: BUILD NOT RUN (в среде разработки нет Flutter). Тесты написаны, не запускались.

## Решение по ТЗ
Личный таймлайн чата показывает свои события и только те чужие, которые
оператор сам привязал к этому чату (вариант «Б»). Это делается на Этапе 2.

## Что сделано
- Миграция v3 (только добавления): `chat_members.color_tone`, `chat_members.removed_at`.
- Цвет — свойство участника в группе; новому участнику выдаётся свободный
  цвет палитры, вернувшийся получает прежний; оператор меняет цвет вручную
  (Сведения о группе → кружок цвета у участника).
- Удаление из группы «мягкое»: строка остаётся с `removed_at`. Старые
  сообщения бывшего участника сохраняют автора, имя и цвет.
  Число участников в шапке считается только по действующим.
- Отмена добавления участника («Назад», сброс сцены) удаляет строку совсем,
  если у него нет сообщений в группе (`removeMember(forget: true)`).
- Старые группы без сохранённого цвета выглядят как раньше (цвет по имени).
