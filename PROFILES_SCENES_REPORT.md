## Как работают события на нескольких профилях

**«Алексей → Марина: «Ты где?»»**
- На телефоне Алексея — исходящее в чате с Мариной.
- На телефоне Марины — входящее в чате с Алексеем.
- Если у персонажа нет профиля, его копии нет.

**Статус «Отправляется» или «Не доставлено»** — у Марины сообщения нет.
Событие статуса «Доставлено» доставляет его: оно появляется у Марины
в этот момент.

**Удаление или правка сообщения события** — на обоих телефонах.

**«Сергей → Алексей: звонок»:**
- на экране профиль Алексея — у него экран входящего звонка, у Сергея
  по окончании запись «исходящий»;
- на экране профиль третьего персонажа — звонок идёт «за кадром»,
  ответ и завершение задаются событиями, в историю обоих он попадает
  по окончании;
- «Сергей завершает звонок» до ответа: у Алексея — **пропущенный**,
  у Сергея — **отменённый**.

«Назад», «СБРОС СЦЕНЫ» и откат репетиции работают для всех профилей сразу.

## Ограничения

- **Проекты.** Проектов как отдельной сущности нет: одно приложение —
  один проект.
- **Параллельность.** Одновременные события выполняются подряд, без
  задержки, а не буквально параллельно.
- **Один звонок на экране.** Звонки «за кадром» — без ограничения
  количества.
- **Перемотка к моменту времени** — переход к шагу с откатом последующих
  (было ранее). Непрерывной перемотки нет.
- **Ссылки на события** («статус сообщения события №3») работают
  в пределах одного прогона. После перезапуска приложения посреди
  дубля сброс работает, а ссылки на события прошлого запуска — нет.
- **В редакторе таймлайна групповых действий пока нет** (из C3).

## Как проверить на телефоне

1. **Профили.** Настройки → Профили телефона → «Создать профиль» ×2
   (Марина, Сергей) → переключиться → пустые телефоны → вернуться
   к Максиму: всё на месте.
2. **Экспорт и импорт.** Долгое нажатие на профиль → «Экспортировать» →
   сохранить → «Импортировать профиль» → выбрать файл → появился
   «(импорт)» с теми же чатами.
3. **Сцена на трёх профилях.** Операторская → новая сцена → «+»:
   - «Сообщение: кто → кому» (Максим → Марина, статус «Отправлено»);
   - «Изменить состояние» → «событие №1» → «Доставлено»;
   - «Звонок: кто → кому»;
   - «Завершить звонок» → выбрать звонок.

   СТАРТ → «Далее» по шагам, переключаясь между профилями.
4. **Репетиция.** «🎭 Репетиция» → СТАРТ → пройти → всё откатилось.
   «🎬 Дубль» → осталось → «🔄 Повторить сцену».
