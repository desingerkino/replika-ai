## Как обновить на GitHub

**Три приёма, как раньше:**
1. Папка **lib** на GitHub → **Add file → Upload files** → папки `features`
   и `app` → **Commit changes**.
2. Снова в **lib** → `core`, `data`, `main.dart` → **Commit changes**.
3. Корень → папки `test` и `tool`, файлы `pubspec.yaml`, `README.md`,
   `QA_CHECKLIST.md`, `STAGE_10_11_REPORT.md` → **Commit changes**.

**Плюс одна правка файла сборки** (`.github/workflows/main.yml`, прямо
в браузере):
1. Откройте файл и нажмите карандаш ✏️.
2. Найдите строку `      - name: Тесты`.
3. Перед ней вставьте три строки:
   ```
         - name: SQLite для тестов
           run: sudo apt-get update -qq && sudo apt-get install -y -qq libsqlite3-dev

   ```
   Отступ — 6 пробелов перед `- name`, как у соседних шагов.
4. **Commit changes**.

Без этой правки интеграционные тесты могут не найти SQLite. APK при этом
всё равно соберётся: тесты идут после сборки.
