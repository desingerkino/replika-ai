# Видеозвонок: переключение камеры + автозапись в галерею

## 1. Изменённые файлы
Новые:
- `packages/replika_recorder/` — маленький локальный плагин записи экрана (Dart, Swift, Java).
- `lib/app/call_video_recording.dart` — логика записи звонка (старт, остановка, имя файла, галерея, запасное сохранение).
- `test/call_video_recording_test.dart` — автотест логики (с подставным рекордером).

Изменённые:
- `lib/features/call/call_screen.dart` — запись по фазам звонка, кнопка «Перевернуть», закрытие записи при сворачивании/закрытии экрана.
- `lib/features/call/camera_self_view.dart` — `CameraSelfController`, переключение камер.
- `pubspec.yaml` — зависимость на локальный плагин.
- `tool/prepare_ios.sh` — `NSPhotoLibraryAddUsageDescription`.

Не тронуты: CallEngine, сценарии, таймлайн, операторский режим, группы, уведомления, дизайн.

## 2. Зависимости
Внешних пакетов не добавлено. Добавлен один локальный плагин `replika_recorder` (path), потому что `camera` не умеет записывать интерфейс звонка, а готовые пакеты записи экрана устарели или тянут FFmpeg.

## 3. Переключение камеры
`CameraController.setDescription(...)` на том же контроллере: звонок, звук (микрофон звонка — состояние CallEngine) и экран не трогаются. Если плагин камеры не смог — контроллер пересоздаётся с другой камерой; если и это не вышло — возвращается прежняя, показывается плашка. Нет второй камеры — кнопка не показывается. Выбранная камера запоминается при сворачивании.

## 4. Запись
Записывается экран приложения со звуком: интерфейс Replika, камера, видео собеседника, нажатия кнопок и сама смена камеры → один mp4.
- iPhone: ReplayKit (`RPScreenRecorder`), микрофон включён.
- Android: MediaProjection + MediaRecorder (H.264/AAC), служба переднего плана типа mediaProjection.
Старт — когда звонок перешёл в «Соединение/Разговор». Остановка — через ~0,9 с после «Звонок завершён», либо сразу при закрытии экрана, сворачивании приложения, ошибке. Закрытие идемпотентно (ровно один раз). Сбой записи никогда не ломает звонок.

## 5. iPhone: куда сохраняется
Приложение «Фото» (альбом «Недавние»), имя `Replika_ГГГГ-ММ-ДД_чч-мм-сс.mp4` (оригинальное имя ресурса).

## 6. Android: куда сохраняется
Галерея, папка `Movies/Replika` (MediaStore, Android 10+; на 9 и ниже — запись в Movies/Replika). Имя такое же.
Если в галерею не вышло — файл остаётся в папке приложения `call_recordings/` и показывается плашка.

## 7. Разрешения
- iOS: `NSPhotoLibraryAddUsageDescription` (только добавление в «Фото»). Камера и микрофон уже были.
- Android: `FOREGROUND_SERVICE_MEDIA_PROJECTION`, `FOREGROUND_SERVICE` (уже были), `WRITE_EXTERNAL_STORAGE` только для Android ≤ 9 (maxSdk 28). Читать галерею не нужно. Камера и микрофон уже были.
- Системные окна: iOS — «Начать запись экрана», Android — «Начать запись/трансляцию» (на Android 14 выбрать «Весь экран»).

## 8. Что проверено
Здесь, в песочнице, Flutter/Xcode/Android SDK нет — собрать и запустить код нельзя. Проверено только чтением кода и автотестом (будет выполнен в CI): имя файла, один файл на звонок, однократное закрытие, остановка во время запуска, отказ в записи, запасное сохранение.
Тест на телефоне (ваш сценарий 1–17) ещё нужно пройти: сначала iPhone, потом Android.

## 9. Ограничения платформ
- ReplayKit/MediaProjection каждый раз показывают системное окно подтверждения — убрать нельзя.
- Запись идёт, пока приложение на экране. Свернули/заблокировали — запись закрывается и сохраняется, продолжение — отдельным файлом не создаётся.
- Системные баннеры/кнопка остановки записи могут быть видны в самом видео (iOS — красная метка статуса).
- Android: звук — только микрофон (звук собеседника из динамика пишется, если слышен микрофону). Под Android 14 каждый звонок требует нового подтверждения.
- Сброс сцены во время звонка завершает звонок → запись закрывается и сохраняется.
- Звонки, на которые не ответили, не записываются (запись стартует при соединении).
- Нативный код не компилировался; возможны правки после первой сборки CI.
