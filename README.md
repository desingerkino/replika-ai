# Реплика — постановочный мессенджер для съёмок (Android, iPhone, iPad)

Платформы: Android и iOS (iPhone, iPad) из одного проекта. iOS: `IOS_SETUP.md`, итоги портирования и непроверенное — `IOS_PORT_REPORT.md`, команды оператора — `OPERATOR_COMMANDS.md`.

Приложение-реквизит: выглядит и ведёт себя как настоящий мессенджер,
но все данные — персонажи, переписки, сцены — живут только на телефоне.
Без сервера, аккаунта и интернета; сервисы Google не нужны (подходит Huawei).

Статус: **Этапы 1–11** — 10 (полировка) продолжается по замечаниям с телефона; чек-лист проверки — `QA_CHECKLIST.md` — архитектура, мессенджер, медиа и операторский
режим со сценами (редактор таймлайна, Scene Engine, ручной и автоматический
запуск, «СБРОС СЦЕНЫ», дубли, несколько телефонов). Честный статус каждого
этапа — в файлах `STAGE_N_REPORT.md`.

## Операторская

- Вход: Настройки → Дополнения → Операторский режим; скрыто — удерживать
  заголовок «Чаты» 2 секунды или три пальца на экране 1 секунду.
- Пульт во время дубля: громкость вверх — «Далее», вниз — «Назад»,
  обе кнопки 1,2 секунды — «Сброс сцены». Вне дубля кнопки меняют громкость.
- Дополнительно в кадре: касание двумя пальцами — «Далее».
- Сцена — это участники: в редакторе «Участники → Добавить» (сколько угодно),
  у каждого действия — «От имени участника». На панели: выбрать участника
  и нажать «Сообщение» / «Звонок» / «Удалить» / «Ещё» — действие уходит
  в его чат; «Записывать в таймлайн» превращает ручные действия в сценарий.
- На панели: нажмите шаг таймлайна — «Перейти сюда» или «Выполнить сейчас»;
  в автоматическом режиме — скорость и обратный отсчёт.
- Импровизация (операторская → «Импровизация»): ответ собеседника вручную или
  из заготовок; очередь ответов — в кадре громкость вверх отправляет следующий
  ответ с «печатает…», вниз отменяет последний. ИИ не подключён.
- Звонки: кнопки в шапке чата и в профиле, вкладка «Звонки», действия звонков
  в таймлайне сцены. Голос и видео собеседника — в его карточке («Для
  постановочных звонков»). Пульт вне дубля: на вызове громкость вверх —
  «собеседник ответил», вниз — «сбросил / положил трубку».
- Запись в чате: микрофон в поле ввода — голосовое с настоящей «волной»;
  скрепка → «Записать видеосообщение» — круглое видео фронтальной камерой.
- Уведомления: настоящие уведомления Android о входящих (сцена, импровизация,
  пропущенный звонок), переход в чат по нажатию; в сценах — «Локальное
  уведомление» с любым заголовком, смена текста и времени, событие в чате.
- Connect (Настройки → Дополнения → Connect): управление телефоном с будущего
  Prop Controller по Wi-Fi без интернета — сопряжение по коду, шифрование,
  команды через сцену Connect. Протокол: `PROP_CONTROL_PROTOCOL.md`.
- Кинорежим (операторская → «Кинорежим»): своя строка состояния с нужным
  временем, зарядом и сетью; служебные пункты настроек скрыты; «назад»
  не закрывает приложение.
- «Время в кадре» (в редакторе сцены): сообщения сцены показывают заданное
  время, например 23:47.
- Демо: сцена «12. Вероника у офиса» уже создана — откройте панель и нажмите «СТАРТ».

## Как получить APK без установки Flutter (GitHub Actions)

Сборку делает бесплатный сервер GitHub. На компьютере ничего ставить не нужно,
поэтому способ подходит и для MacBook на Catalina.

1. Зарегистрируйтесь на github.com.
2. Нажмите **New repository**, выберите **Private**, затем **Create repository**.
3. На странице репозитория выберите **uploading an existing file**
   и перетащите **всё содержимое** архива.
   Папка `.github` на Mac скрыта. Чтобы её увидеть, нажмите в Finder `Cmd + Shift + .` —
   без этой папки сборка не запустится.
4. Нажмите **Commit changes**. На вкладке **Actions** автоматически начнётся
   «Сборка APK» (7–12 минут).
5. Когда сборка позеленеет, откройте её. Внизу, в разделе **Artifacts**, скачайте
   `replika-apk`: это zip, внутри лежит `app-release.apk`.
6. Перенесите APK на телефон и установите
   (понадобится разрешить установку из неизвестных источников).

Если сборка покраснела, откройте упавший шаг, скопируйте текст ошибки
и пришлите его — это самый быстрый путь к исправлению.

## Сборка на Mac с Apple Silicon (M1 и новее)

Нужны Flutter (канал stable) и Android Studio с Android SDK.

```bash
bash tool/prepare_android.sh   # создаёт android/, ставит название и иконки
flutter pub get
flutter test                   # автотесты
flutter build apk --release
```

Готовый файл: `build/app/outputs/flutter-apk/app-release.apk`.

Папка `android/` не хранится в проекте: её создаёт `flutter create` под
установленную версию Flutter, поэтому версии Gradle всегда совместимы.
Скрипт можно запускать повторно.

## Структура

```
lib/
  app/            запуск, службы, навигация, живые запросы к базе
  core/brand/     название и логотип
  core/design/    дизайн-система: токены, цвета, шрифты, темы, компоненты
  core/util/      даты по-русски, идентификаторы, JSON, поиск
  data/db/        SQLite: схема, миграции, шина изменений
  data/models/    модели: персонаж, телефон, чат, сообщение, сцена, дубль…
  data/repositories/  чтение и запись данных
  data/seed/      демо-данные первого запуска
  features/       экраны: чаты, открытый чат, контакты, профиль,
                  избранное, поиск, настройки, медиатека и просмотр медиа
test/             автотесты
tool/             подготовка Android и iOS, общая конфигурация, генератор иконок
```

### Устройство данных

- **Персонаж** существует один раз на весь проект.
- **Виртуальный телефон** — точка зрения: у каждого свой владелец, свои контакты
  и чаты. Так реализуется съёмка с нескольких телефонов.
- **Контакт** — то, как персонаж записан на конкретном телефоне: например,
  Вероника Лебедева на телефоне Максима записана как «Красотка».
- У каждого сообщения есть **происхождение**: базовая переписка, сцена или
  импровизация. На этом строится «СБРОС СЦЕНЫ»: он удаляет только то,
  что добавила сцена.
- Схема базы версионируется: обновление приложения не стирает данные.

### Дизайн-система

- Основной цвет — петроль `#155E75`, акцент — вольфрам `#E3A13B`
  (тёплый свет ламп на площадке), текст — «чернила» `#15202B`.
- Шрифт системный: в кадре приложение выглядит родным для телефона.
- Светлая и тёмная темы следуют настройке телефона.
- Операторская панель будет всегда тёмной, чтобы не давать бликов.
- Все цвета, отступы и радиусы задаются только через `lib/core/design/`.

## Демо-данные

При первом запуске создаётся «Телефон Максима» с контактами Красотка, Мама,
Алексей и Работа и реалистичными переписками. Время сообщений считается
от момента первого запуска. **Номера телефонов вымышленные** — перед съёмкой
замените их на согласованные с площадкой.

## Смена названия

«Реплика» — рабочее название. Чтобы его поменять, исправьте его в двух местах:
`lib/core/brand/brand.dart` и `APP_LABEL` в `tool/prepare_android.sh`.
Иконка перерисовывается командой `python3 tool/generate_icons.py` (нужен Pillow).
