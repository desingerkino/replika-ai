## Группы в самом Messenger

- **Новая группа.** Значок группы в заголовке «Чаты» → название
  и участники из контактов → «Создать». Первым в группе появляется событие
  «Вы создали группу «…»».
- **Список чатов.** Название группы, аватар по названию, превью
  «Красотка: текст» / «Вы: текст».
- **Экран группы:**
  - в шапке — «3 участника» или «печатает…»;
  - над первым пузырём подряд — имя отправителя, у каждого свой цвет;
  - звонков в группе нет — кнопки скрыты.
- **Сведения о группе** (нажатие на шапку): переименовать, добавить
  участников, удалить участника. Каждое действие — серое событие
  в переписке.
- **Где работают группы:** поиск, избранное, ответы, медиа, уведомления.
  Импровизация — только в личных чатах: у группы нет одного собеседника.

База данных не менялась: таблицы и поля групп были заложены в Этапе 1.

## Группы в Scene Engine

- **Сообщения в группу.** Любое сообщение, медиа и «печатает…» можно
  адресовать группе параметром `groupId`. Отправитель должен состоять
  в группе.
- **Новые действия:** «Создать группу», «Добавить в группу», «Удалить
  из группы» — с событием в переписке и отменой. «Назад» и «СБРОС СЦЕНЫ»
  удаляют созданные сценой группы и возвращают состав остальных.
- **В редакторе таймлайна** этих трёх действий пока нет: у них нет
  удобного выбора группы. Они выполняются через Connect и экран группы.

## Группы в Connect

- **Новые и дополненные команды:**
  - LIST_GROUPS;
  - CREATE_CHAT, ADD_PARTICIPANT, REMOVE_PARTICIPANT;
  - MESSAGE, MEDIA, TYPING с `groupId`;
  - EDIT, DELETE, STATUS по `messageId` для сообщений группы.
- **`groupId` — ключ Controller** (`crew`). Он одинаков на всех телефонах.
- **Проверки:** отправитель не в группе, повтор ключа, неизвестная
  группа, неверный ключ, пустой состав → понятные ошибки.
- **«Проверка Connect»:** «ГРУППА: создать» и «ГРУППА: сообщение
  участника».

## Как проверить на телефоне

1. «Чаты» → значок группы → название, два контакта → «Создать».
2. В группе написать сообщение; в сведениях добавить и удалить участника —
   появятся события.
3. «Проверка Connect» → подключиться → «ГРУППА: создать» → «ГРУППА:
   сообщение участника»: в списке «Съёмочная группа», в чате — имя
   отправителя над пузырём.
4. «RESET_SCENE» — группа из проверки исчезает, ваша группа остаётся.
