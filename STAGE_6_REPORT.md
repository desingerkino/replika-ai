## РЕАЛИЗОВАНО (в коде; подтвердит только сборка и запуск)

- **Экран «Импровизация»** (Операторская → Импровизация):
  - выбор чата: по умолчанию — чат текущей сцены;
  - ответ собеседника вручную: «печатает…» нет / 1 / 2 / 3 / 5 секунд,
    «Отправить от собеседника» или «От владельца»;
  - при ответе собеседника исходящие становятся прочитанными; если чат
    не открыт, растёт счётчик непрочитанных — как у сцены.
- **Заготовки по восьми категориям ТЗ:** короткие, нейтральные, эмоциональные,
  вопросы, согласие, отказ, объяснение, действие.
  - При первом запуске создаются 37 фраз.
  - Добавление, правка и удаление — долгое нажатие на текст.
  - Нажатие на заготовку отправляет её сразу, значок — ставит в очередь.
- **Подсказка категории** по последней реплике героя. Например, на «Ты где?»
  подсказывается «Объяснение», на «Прости» — «Эмоциональные». На экране
  прямо написано: «ИИ-режим не подключён… подсказка — по ключевым словам».
- **Очередь ответов для кадра** — решение для одного телефона в руках актёра:
  - оператор заранее собирает ответы и нажимает «В КАДР С ОЧЕРЕДЬЮ»;
  - громкость вверх (или касание двумя пальцами) — следующий ответ
    с «печатает…»;
  - громкость вниз — отмена последнего: сообщение исчезает, реплика
    возвращается в очередь;
  - «Снять», «Очистить».
- **Порядок управления кнопками громкости:**
  - если идёт дубль сцены — управляют сценой;
  - иначе, если очередь взведена, — очередью;
  - иначе — громкостью.
- **Связь со сценой.** Если в чате идёт дубль, ответы импровизации
  привязываются к сцене, получают «время в кадре» и исчезают
  при «СБРОС СЦЕНЫ».
- **«Убрать импровизацию из этого чата»** — удаляет только сообщения
  импровизации.

## Как обновить на GitHub

Файлов стало больше 100, поэтому загрузка в два приёма через
**Add file → Upload files**:
1. Папка `lib`, затем **Commit changes**.
2. Папка `test`, файлы `pubspec.yaml`, `README.md`, `STAGE_6_REPORT.md`,
   затем **Commit changes**.

Первая загрузка тоже запустит сборку, и она может упасть: тесты
и `pubspec.yaml` ещё старые. Смотрите результат второй сборки.
